<details open>
<summary><b>⚖️ SwapCheck: Is it safe to swap your agent's model?</b></summary>
<br>

A statistically grounded evaluation harness for tool-using LLM agents. It runs a **baseline vs. candidate** model across a scenario suite and returns a **SHIP / HOLD / INCONCLUSIVE** verdict.

- 📊 Paired, scenario-level **bootstrap** (2,000 resamples) with non-inferiority margins and required-sample-size estimates
- 🧮 Multi-tier scoring: deterministic checks, rule-based **policy violations**, and an **LLM-as-judge** calibrated with Cohen's kappa
- 🛡️ 60 YAML scenarios in 5 categories, including **prompt injection** and refund-policy edge cases
- ✅ CI exit codes gate model swaps · 100+ offline tests, no API keys needed

`Python` `LiteLLM` `Typer` `SQLite` `pytest` `GitHub Actions`
&nbsp;·&nbsp; [**Repo →**](https://github.com/abduljalilmemon/SwapCheck)

</details>

<details>
<summary><b>🧑‍🤝‍🧑 Human-AI Group Decision Experiment</b></summary>
<br>

A real-time research platform where **humans and LLM agents** chat and vote together in blind group-decision sessions. Participants must not be able to tell who is human.

- ⏱️ Server-authoritative phase state machine with asyncio timers and reconnect replay
- 🙈 Blind condition enforced by an allow-listed payload layer, so participant type never reaches the client
- 🤖 Human-like AI agents (typing delays, reply probabilities, output filter) with Anthropic → Gemini → scripted fallback
- 🐳 One command to run: `docker compose up --build`

`FastAPI` `WebSockets` `React` `TypeScript` `Tailwind` `PostgreSQL` `Docker`
&nbsp;·&nbsp; [**Repo →**](https://github.com/abduljalilmemon/human-ai-group-decision)

</details>
